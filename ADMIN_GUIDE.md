# 🔧 Admin Settings Guide

## What's New

Your app now includes an **Admin Settings** feature that lets you edit chores, rewards, and passwords **without touching any code**. Everything is updated instantly and works immediately!

---

## How to Access Admin Settings

1. **Log in as Parent**
   - Click "Parent Login"
   - Enter password: `parent123`

2. **Click "⚙️ Admin Settings" Button**
   - Located at the top-right of the parent dashboard
   - The button toggles between "⚙️ Admin Settings" and "👨‍👧‍👦 Dashboard"

3. **Now you're in Admin Mode**
   - Manage everything from one page
   - All changes apply immediately

---

## What You Can Edit

### Parent Password
- See your current parent password
- Click "Change" button to update it
- Enter new password and click "Save"
- Next login will use the new password

### Each Child's Settings

#### Login Password
- Shows current login password
- Edit the input field on the right
- Click outside the input (or press Tab) to save

#### Add New Chore
1. Type chore name in "Chore name" field
2. Enter reward minutes in "Minutes reward" field
3. Click "Add Chore" button
4. Chore appears immediately in the list below

#### Edit Existing Chores
For each chore in the list:
- **Name column**: Click to edit chore name, save on blur
- **Reward column**: Click to edit reward minutes, save on blur
- **Display column**: Shows the reward value
- **Delete button**: Remove chore with confirmation

## Example Workflows

### Change a Chore Reward
1. Go to Admin Settings
2. Find the chore (e.g., "Homework" - 10 min)
3. Click the reward value (10)
4. Change to new value (e.g., 15)
5. Click elsewhere - it saves automatically
6. Jaxon will see 15 minutes next time he logs in

### Add a New Chore
1. Go to Admin Settings
2. Scroll to "Add New Chore" section under the child
3. Type: "Dishes"
4. Type: "20" (for 20 minutes)
5. Click "Add Chore"
6. "Dishes" now appears in their chore list with 20 minute reward

### Update a Child's Password
1. Go to Admin Settings
2. Find their "Login Password" section
3. Click the password input field
4. Change password
5. Click elsewhere to save
6. They'll need to use the new password to log in

### Delete a Chore
1. Go to Admin Settings
2. Find the chore in their list
3. Click the red "Delete" button
4. Confirm in the popup
5. Chore is removed immediately

## Troubleshooting

**Changes don't appear to save?**
- Make sure you click outside the input field (or press Tab)
- Look for the success alert that appears

**Password not updating?**
- Make sure to enter text and click outside the input
- If you change parent password, you'll need the new one to log in again

**Can't add a chore?**
- Make sure you entered both name and reward value
- Look for the alert message if something's wrong
